# ScanProMac

ScanProMac es una aplicación nativa para macOS en Apple Silicon (`arm64`) para escanear documentos con Image Capture / AirScan.

## Funciones

- Escaneo desde cama plana o alimentador.
- Previsualización de una o varias hojas.
- Soporte para alimentador multipágina.
- Guardado rápido en un solo PDF.
- Exportación a PDF, PNG y JPG.
- Optimización de imagen y detección automática de tamaño de hoja.

## Requisitos

- macOS 14 o superior.
- Mac con Apple Silicon (`arm64`).
- Escáner compatible con Image Capture / AirScan.

## Instalación

1. Descarga `dist/ScanProMac.dmg` desde este repositorio.
2. Abre el archivo DMG.
3. Arrastra `ScanProMac.app` a `Applications`.
4. Abre la app desde `Applications`.

Si macOS muestra una advertencia de seguridad, abre la app con clic derecho y selecciona **Abrir**.
